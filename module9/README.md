## Description
This module runs the course clinical-NLP pipeline on a synthetic PDAC ICU cohort and separates genuine early signal from leakage.

The pipeline has five steps:
1. Configure PDAC signals and consequences.
2. Generate 400 patients with 3 notes each.
3. Extract features with ConText-style assertion detection.
4. Train a logistic-regression model of in-hospital death and score it with 5-fold cross-validated AUROC.
5. Use permutation importance to find which features drive the model.

The completed D1 to D4 answers are in the notebook's markdown cells.

## What did not work / limitations
- **The pipeline ran without errors.**
- **Synthetic cohort.** The generator models ICU death from age, lactate, creatinine and the configured signals. It does not capture PDAC stage, resectability or treatment history, so the AUROCs describe this simulation only.
- **Noisy importance.** Permutation importance uses a single 70/30 split (120 test patients), so lower-ranked features are noisy. Some genuine signals show small negative values.
- **Assertion engine limits.** The rule-based engine cannot tell "brief dialysis, since stopped" from ongoing dialysis. It would also mark "s/p stent for obstructive jaundice" as historical.
- **Added cell.** I added one supporting-evidence cell after D2. It shows the per-outcome prevalence and the note type for each concept, plus comparison AUROCs. The provided engine was not edited.
